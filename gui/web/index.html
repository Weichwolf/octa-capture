OCTA-CAPTURE Linux — README

Use MIC PRE and DIRECT MIXER to switch views. Turn knobs by dragging or using the arrow keys; hold Shift for finer steps. Double-click a sensitivity value to type it, then press Enter to apply or Escape to cancel.

Right-click a control for its preset values and available All Ch. actions. Bypass On disables compression. Auto-Sens adjusts the selected inputs to the loudest signal you provide; Cancel restores their previous settings.

Device → Save settings exports an .octa file (Ctrl+S); Load settings imports one (Ctrl+O). The Patch Bay (Ctrl+P) selects the source for each output pair. Multiple Direct Mixer changes that routing to enable A–D.

Choose the sample rate under Driver → Driver Settings; it changes immediately. Audio applications choose their own ALSA buffer size. At 192 kHz only channels 1–4 and Mixer A are available; reverb and patchbay are unavailable.

Click the device name to send its identification command. Right-click it (or press Shift+F10) to select a connected OCTA-CAPTURE. Closing the panel releases its control connection; audio applications continue running.
