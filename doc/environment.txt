Goal
====
The driver must work locally under WSL2 with the connected OCTA-CAPTURE and
later on native Debian. Audio over USB/IP has not been tested yet. This
inventory does not implement a driver.

Kernel build blockers at initial inspection
==========================================
/lib/modules/6.18.54.1-microsoft-standard-WSL2/build pointed to
/usr/src/linux-headers-6.18.54.1-microsoft-standard-WSL2.
That directory contained incomplete include files: no Makefile,
Module.symvers, generated configuration, or modpost.
Consequently, make -C ... kernelrelease failed.
CONFIG_MODVERSIONS=y: modules_prepare alone does not provide Module.symvers.
CONFIG_MODULE_SIG is disabled; modules_disabled=0.
The running kernel configuration is saved in kernel-config.txt.
Microsoft tag linux-msft-wsl-6.18.54.1 was verified using git ls-remote:
d504d40ab83839cb61942a812a99d183c42227b9.
https://github.com/microsoft/WSL2-Linux-Kernel

Setup script
============
/tmp/setup-octa-capture.sh
Run: sudo bash /tmp/setup-octa-capture.sh --user cosmo

Installs required packages and Debian kernel headers. Creates the
octacapture group, audio group membership, OCTA-CAPTURE-specific udev rules,
and usbmon access. User ACLs allow access from existing shells; group
membership takes effect after logging in again. USB capture access covers
all USB buses. It does not configure unrestricted passwordless sudo.

Under WSL, the script also downloads the exact Microsoft kernel source
revision and builds it using the running configuration to generate matching
build files and Module.symvers. This can take time and several GB of disk
space. The build symlink is updated; the running kernel, installed driver
modules, and device firmware are not replaced. A subsequent test module
load is needed to verify ABI compatibility in practice.

After successful setup, /etc/octa-capture-dev.env provides KDIR,
KERNEL_CC, and KDIR_NATIVE. Native Debian uses its own kernel version and
headers. Modules built for the Debian target are not loaded into WSL.

The script had not been run as root at the time of the initial inspection.
Shell syntax and ShellCheck passed. Package installation, permission changes,
and the kernel build must be verified after setup. Raw inspection output:
check-*.txt. Later setup activity is not reflected in this initial snapshot.
